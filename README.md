## Workspace layout

```text
INS2053/
|-- docs/                 Course links and personal notes
|-- exercises/            In-class practice, one folder per session
|-- homework/             Weekly homework, one folder per session
|-- project/              Capstone website, developed throughout the course
|-- .gitignore
`-- README.md
```

## Weekly workflow

1. Read the matching ebook chapter and complete the Try It Yourself blocks.
2. Keep in-class work in `exercises/session-NN/`.
3. Complete the brief in `homework/session-NN/` and keep all website files there.
4. Test the homework locally in a browser before pushing it to GitHub.
5. Add the week's improvement to `project/` as the capstone grows.
